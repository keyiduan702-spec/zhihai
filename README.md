# 知海

> 知识如海，日日有迹。

知海是一款融合知识管理、智能复习与个人成长记录的学习平台。它以月历呈现学习轨迹，根据掌握程度组织复习任务，帮助用户在即将遗忘之前重新遇见知识。

## 核心功能

- **学习月历**：按日期查看学习记录与复习任务，清晰回顾每日进度。
- **今日复习**：集中展示到期和逾期内容，可随时标记完成状态。
- **持久化笔记**：使用本地 D1 数据库新增、编辑、保存和删除笔记，刷新或重启后数据仍然存在。
- **全文搜索**：按主题、正文和文件名快速找回学过的内容。
- **学习记录**：记录学习主题、具体内容和掌握程度，并生成后续复习计划。

## 本地运行

环境要求：Node.js `>=22.13.0`。

```bash
npm install
npm run local
```

启动后访问 [http://localhost:8787](http://localhost:8787)。

本地版本无需账号密码，打开地址后直接进入知海。

笔记数据保存在项目目录下的 `.wrangler/state/v3/d1` 中。该目录已加入 `.gitignore`，因此私人笔记不会上传到 GitHub。请不要手动删除 `.wrangler` 目录，否则本地笔记会丢失。

如需启动前端开发模式：

```bash
npm run dev
```
